# Chat `/mode` — Implementation Plan (parity PR 3 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/mode ask|edits|plan|skip` switches the chat window's permission mode from the next turn, mapped to what each harness supports, with the bar showing the mode per harness.

**Architecture:** A `mode` string on `ChatConfig` becomes the source of truth; `skip_permissions` stays as the wire-level bool the runtimes already read and is derived from it. Each runtime maps the mode to its own flag or request field at the top of `run_turn`. The window's `/skip-permissions` becomes an alias over one `set_mode`, and the bar mark becomes the mode word with a `?` when a harness cannot honor it and `cfg` when an explicit codex key overrides it.

**Tech Stack:** Python 3.12, pytest, the fake claude/codex/opencode servers under `tests/fakes/`.

**Spec:** `docs/specs/2026-09-26-chat-parity-design.md`, section 4 ("`/mode`"). Section 3 is PR 4 and out of scope.

## Global Constraints

- No new dependency. Nothing in `tandem native` changes: the top-level `skip_permissions` key and the `--[no-]skip-permissions` flag keep their meaning there.
- Codex `approvalPolicy` on the wire is `untrusted | on-request | never`; `on-failure` does not exist and is never sent.
- Precedence for the initial mode: launch flag (`--skip-permissions` → `skip`, `--no-skip-permissions` → `ask`), then an explicit `[chat] mode`, then the legacy top-level `skip_permissions = true` → `skip`, then `ask`.
- A running turn keeps the mode it started under: every `run_turn` takes `cfg = self.cfg` as its first statement and uses that local everywhere below — never `self.cfg` again — because codex reads its overrides after the blocking `initialize` and opencode after `ensure_server` and the command load, and `set_cfg` replaces `self.cfg` from the main thread meanwhile. (Codex spec-review finding.)
- Tests that construct `ChatConfig(skip_permissions=True)` directly must keep working: the runtimes consult `cfg.effective_mode`, which is `skip` whenever `skip_permissions` is set.
- Commit messages follow the repo's imperative style and end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Run the suite with `uv run pytest -q`; the baseline on `main` at `c472f5a` is 1495 passed.

## Review Focus

1. `/skip-permissions off` while the mode is `plan` must land on `ask`, not stay in `plan`. (Task 4: `test_skip_permissions_off_from_plan_lands_on_ask`.)
2. A bare `/skip-permissions` while the mode is `edits` must go to `skip` (it toggles skip-ness, not "the other way" from an arbitrary mode). (Task 4: `test_a_bare_skip_permissions_toggles_skip_ness`.)
3. `[chat] mode = "plan"` in the config plus `--skip-permissions` on the launch must yield `skip`; `--no-skip-permissions` must yield `ask`. (Task 1: `test_the_launch_flag_beats_a_chat_mode`.)
4. Codex `edits` with an explicit `codex_sandbox = "read-only"` must send `on-request` + `read-only`, and the bar must say `cfg` for codex. (Task 3: `test_an_explicit_codex_key_wins_over_the_mode`; Task 4: `test_the_bar_says_cfg_when_a_codex_key_overrides_the_mode`.)
5. Opencode in plan mode running a listed command (`/init`) must carry `agent: "plan"` on the command endpoint too, not only on messages. (Task 3: `test_plan_mode_rides_the_command_endpoint_too`.)
6. `/mode` typed while a turn is still starting up (codex inside `initialize`, opencode inside `ensure_server`) must not change that turn's permissions. (Task 2: `test_a_mode_change_during_startup_does_not_reach_the_running_turn` for codex; Task 3: the same name for opencode.)

```python
def _resolve_mode(config: dict, raw) -> str:
    """The window's initial permission mode: the launch flag, else an
    explicit `[chat] mode`, else the legacy top-level `skip_permissions`,
    else ask. The flag is a bool, so it can only say skip or ask."""
    if _skip_permissions_override is not None:
        return "skip" if _skip_permissions_override else "ask"
    chat_mode = raw.get("mode") if isinstance(raw, dict) else None
    if isinstance(chat_mode, str) and chat_mode in MODES:
        return chat_mode
    return "skip" if config.get("skip_permissions") is True else "ask"
```

```python
    def mode_marks(self) -> dict[str, str]:
        """The bar's word per harness: the mode for every mode but ask; `?`
        when the harness cannot honor it and runs as ask (opencode has no
        edits or skip); `cfg` when an explicit `[chat] codex_*` key decides
        codex's column instead of the mode."""
        mode = self.cfg.effective_mode
        if mode == "ask":
            return {}
        marks = {}
        for h in self.session.participants:
            if h == "codex" and (self.cfg.codex_approval_policy or self.cfg.codex_sandbox):
                marks[h] = "cfg"
            elif h == "opencode" and mode != "plan":
                marks[h] = f"{mode}?"
            else:
                marks[h] = mode
        return marks

    def _harness_words(self) -> list[str]:
        """`claude default · codex inherit · opencode build`: what each
        harness is actually sent for the current mode."""
        mode = self.cfg.effective_mode
        claude = CLAUDE_MODES.get(mode, "default")
        policy, sandbox = CODEX_MODES.get(mode, ("", ""))
        policy = self.cfg.codex_approval_policy or policy
        sandbox = self.cfg.codex_sandbox or sandbox
        codex = f"{policy or 'inherit'}/{sandbox}" if sandbox else (policy or "inherit")
        opencode = "plan" if mode == "plan" else ("build" if mode == "ask" else f"{mode}?")
        return [f"claude {claude}", f"codex {codex}", f"opencode {opencode}"]

    def mode_line(self) -> str:
        return " · ".join([f"mode {self.cfg.effective_mode}", *self._harness_words()])

    def set_mode(self, mode: str) -> None:
        """`/mode WORD` and the `/skip-permissions` alias. This window only,
        like the launch flag: nothing is written to the config. A turn
        already running keeps the mode it started under."""
        self.cfg = self.cfg.with_mode(mode)
        self.dispatcher.set_cfg(self.cfg)
        self.screen.note(f"mode {mode} from the next turn · " + " · ".join(self._harness_words()))

    def mode_command(self, arg: str) -> None:
        if arg == "":
            self.screen.note(self.mode_line())
        elif arg in MODES:
            self.set_mode(arg)
        else:
            self.screen.note("usage: /mode [ask|edits|plan|skip]")

    def set_skip_permissions(self, arg: str) -> None:
        """The alias: `on` is `/mode skip`, `off` is `/mode ask`, bare flips
        skip-ness — from any mode that is not skip, to skip."""
        if arg not in ("", "on", "off"):
            self.screen.note("usage: /skip-permissions [on|off]")
            return
        skip = arg == "on" if arg else self.cfg.effective_mode != "skip"
        self.set_mode("skip" if skip else "ask")
```
